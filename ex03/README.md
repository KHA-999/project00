# Project 00: Linux & Git Basics

## Overview
This project covers Linux terminal navigation, file manipulation, and Git/GitHub version control workflows.

## Why Git Makes Development Easier
Git simplifies software development by providing a reliable version control system. It safeguards code by allowing developers to save snapshots of their progress, making it easy to revert to previous working states if errors occur. Furthermore, Git tracks the full history of changes, showing who made specific updates and why, which essentializes team collaboration and prevents code conflicts.
